# Security Policy

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

We take the security of this project seriously. To ensure the safety of our users, we ask that you report all security vulnerabilities privately by email to
[gearmand-security@googlegroups.com](mailto:gearmand-security@googlegroups.com).
This is a private list that only the maintainers can read.

### How to Report

Please include in your email:

* a detailed description of the vulnerability,
* the gearmand version or commit you tested,
* steps to reproduce it,
* any potential impact or mitigations you are aware of.

### What Happens Next

* **Acknowledgment:** Our maintainers will acknowledge receipt of your report within 5 days.
* **Investigation:** We will investigate the issue and keep you updated on our progress by email.
* **Resolution:** Once a fix is ready, we will coordinate a release and then publicly disclose the vulnerability.

Thank you for helping keep this project safe!
