# Security Policy

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

We take the security of this project seriously. To ensure the safety of our users, we ask that you report all security vulnerabilities securely using **GitHub's native private vulnerability reporting web interface**.

### How to Report

1. On GitHub, navigate to the main page of this repository.
2. Under the repository name, click on the **Security** tab.
3. In the left sidebar, under "Reporting", click **Vulnerability reporting**.
4. Click **Report a vulnerability**.
5. Fill out the form with a detailed description, steps to reproduce, and any potential impact or mitigations.
6. Click **Submit report**.

If you cannot use GitHub, email the maintainers at
[gearmand-security@googlegroups.com](mailto:gearmand-security@googlegroups.com)
instead. This is a private list that only the maintainers can read.

### What Happens Next

* **Acknowledgment:** Our maintainers will acknowledge receipt of your report within 5 days.
* **Investigation:** We will investigate the issue and keep you updated on our progress through the private advisory thread.
* **Resolution:** Once a fix is ready, we will coordinate a release and publicly disclose the vulnerability via a GitHub Security Advisory.

Thank you for helping keep this project safe!
